# 丝路译讯 / Silk Road Brief

Статический китайскоязычный портал для китайских компаний и инвесторов, работающих с Казахстаном. Сайт агрегирует открытые источники, дедуплицирует материалы, переводит и классифицирует их в GitHub Actions, валидирует JSON и публикует готовую сборку на Hoster.kz.

## Что реализовано

- современный адаптивный интерфейс на упрощённом китайском;
- главная, архив и карточка новости;
- каталоги госорганов Алматы, Астаны и Шымкента;
- восемь бизнес-инструкций с официальными ссылками и статусом проверки;
- разделы тендеров, источников, методологии, проекта и 404;
- RSS/HTML-адаптеры для официального, делового и нормативного источников;
- серверный AI-перевод через OpenAI Responses API со строгой JSON Schema;
- дедупликация, лимиты запросов, кэш, журнал запуска и безопасный fallback;
- автоматическая синхронизация три раза в день и публикация готовой ветки `production` для Git-развёртывания Plesk на `oguz.kz`.

## Локальный запуск

```bash
npm ci
npm test
npm run validate:data
npm run build
npx serve dist
```

Без `OPENAI_API_KEY` и `OPENAI_MODEL` сборщик новостей работает в безопасном режиме: проверяет реальные источники, сохраняет непереведённые материалы только в локальный черновик и не публикует их на сайт.

## Настройка Hoster.kz и GitHub Actions

Добавьте в **Settings → Secrets and variables → Actions**:

- `OPENAI_API_KEY` — API-ключ перевода;
- `OPENAI_MODEL` — модель с поддержкой Structured Outputs.

В Plesk откройте **Сайты и домены → Git → Добавить репозиторий**. Укажите удалённый репозиторий `https://github.com/demessinm-glitch/SilkWay-Bussnes-News.git`, ветку `production` и путь развёртывания `/httpdocs`. Репозиторий публичный, поэтому FTP-пароль или GitHub-токен Plesk не нужны.

Workflow `content-sync.yml` запускается в 06:15, 12:15 и 18:15 по времени Алматы и коммитит только проверенные данные. После изменения ветки `main` workflow `deploy-hoster.yml` повторно запускает тесты, собирает `dist` и публикует только готовые статические файлы в ветку `production`. Plesk получает эту ветку и развёртывает её в `/httpdocs`. GitHub Pages не используется.

## Команды

```bash
npm run sync:news       # собрать и перевести новости
npm run sync:officials  # обновить публичные каталоги чиновников
npm run sync:guides     # проверить каталог инструкций
npm run sync:tenders    # проверить текущий тендерный набор
npm run sync:all        # выполнить весь конвейер
npm run validate:data   # проверить JSON Schema через Ajv
npm run build           # создать безопасный статический артефакт dist/
```

## Принципы

- Никаких вымышленных новостей или тендеров.
- Оригинальная ссылка и источник сохраняются для каждой публикации.
- Контент источников считается недоверенными данными, а не инструкциями для AI.
- Низкая уверенность, подозрительные цифры и неполные записи не публикуются автоматически.
- Машинный перевод носит справочный характер и не заменяет оригинал или профессиональную консультацию.
